# Beagle & Decent Network — bugs and suggestions

This is where you report a problem or suggest something for **Beagle Chat** (iPhone, iPad, Android, desktop, web,
browser extension), the **agentnet** desktop network, and the **AI agents** you talk to in Beagle. The team reads
every issue, and you can follow each one from report to release.

在这里报告问题或提出建议：Beagle Chat（iPhone、iPad、Android、电脑、网页、浏览器扩展）、agentnet，以及在 Beagle 里对话的
AI 助手。每一条我们都会看，你也可以一直跟进到修复发布。

## Report a problem · 报告问题

1. Search the [open issues](../../issues) first. If yours is there, add a 👍 or a comment with what you saw.
2. Otherwise choose **[Bug report](../../issues/new?template=bug.yml)** and fill in the form.
   - Your **app version and build**, e.g. `1.8.43 (606)`. Find it at the bottom of the Account panel.
   - **What happened**, what you expected, and the steps to make it happen again.
   - Your network if it matters: Wi-Fi, mobile data, switching between them, VPN.

## Suggest something · 提建议

Choose **[Suggestion](../../issues/new?template=suggestion.yml)**: what you'd like, and what it would let you do.

## ⚠️ Everything here is public · 这里的内容全部公开

Don't post your **address, user ID, recovery phrase, keys, passwords, or private messages**. Crop screenshots so they
show only the problem. If a report needs private details, say so in the issue and we'll contact you.

请不要贴出你的地址、用户 ID、助记词、密钥、密码或私人聊天内容；截图只保留和问题有关的部分。

## What the labels mean

| label | meaning |
|---|---|
| `bug` / `suggestion` | the kind of issue |
| `ios`, `android`, `desktop`, `web`, `extension`, `agents`, `network` | where it happens |
| `in progress` | someone is working on it |
| `fixed, not released` | fixed and in a test build, not in the store yet |
| `needs info` | we need more from you to go on |

An issue is closed once the fix is in a released version, and the closing comment names that version.
